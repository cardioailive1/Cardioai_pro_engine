Automation Tier Engine escalation policy, not diagnosis

Decides how much autonomy the engine exercises for a finding: auto-escalate (URGENT), recommend to a clinician awaiting sign-off, or log only (INFORMATIVE). URGENT requires both a confirmed urgent ICD-10 code (STEMI: I21.19 / I21.09) and ≥95% cross-modal confidence — either alone is not enough. The live ECG-only pipeline always passes an empty ICD-10 list, so it can only ever reach RECOMMENDATION or INFORMATIVE; URGENT is only reachable once a real, coded diagnosis exists.

Algorithmic Bias Audit Protocol clinical AI equity

Audits the engine's live inference model against a labeled cardiovascular validation cohort stratified by race/ethnicity, gender, and age band, then runs threshold-based remediation to close any gap. Equity target: ≤2.0 percentage-point sensitivity (true-positive-rate) gap across subgroups, per the product's FDA 2024 digital health equity guidance commitment.

No audit run yet this session. Click "Run audit" to score a synthetic validation cohort against the engine's live model.
Validation cohort is synthetic — no real patient data. The per-subgroup representation gap used to seed baseline disparity is a deliberately injected demo effect standing in for the well-documented mechanism where under-representation in training data weakens a model's signal for that subgroup; it is not a clinical finding. Statistical framework (subgroup confusion matrices, equal-opportunity gap, threshold-based remediation) is real and runs unchanged against a trained model once one exists.
